⚙️ 1. TERMUXNI SOZLASH

Termuxni ochib, dastlabki sozlamalarni bajaramiz va telefon xotirasiga ulanamiz.

pkg update && pkg upgrade -y termux-setup-storage

* termux-setup-storage telefoningiz xotirasiga kirishga ruxsat beradi.

📂 2. MT MANAGER BILAN ISHLASH

MT Manager orqali Termux ichidagi fayllarni ko'rish, o'zgartirish va tahrirlash juda oson.

  1. MT Manager'ni oching. Chap menyudan Add local storage ni bosing.
  2. Ichki xotiradan Termux papkasini topib, Use this folder ni bosing.
  3. Endi Termuxdagi barcha kodlarni MT Manager orqali ochib, xuddi kompyuterdagidek tahrirlashingiz mumkin.
🐍 3. PYTHON VA KUTUBXONALAR

Python o'rnatamiz, papka yaratamiz va kerakli kutubxonalarni o'rnatishni o'rganamiz.

1. Python va Pip o'rnatish:

pkg install python -y

2. Papka yaratish va fayl ochish (name/name.py):

mkdir name cd name nano name.py

* Ichiga print('Salom') deb yozib, CTRL+X, Y, Enter bilan saqlang.

3. Kodni ishga tushirish usullari:

# 1. Papka ichida: python name.py # 2. Papkadan tashqarida: python name/name.py

4. Kutubxonalar o'rnatish (Pip):

pip install requests pip install beautifulsoup4 pip install python-telegram-bot
💡 4. Muhim Buyruqlar
  • cd papka_nomi - papkaga kirish
  • cd .. - bir papka orqaga qaytish
  • ls - papkadagi fayllarni ko'rish
  • clear - ekranni tozalash
☕ 5. JAVA O'RNATISH VA DASTURLASH

Java — bu kuchli dasturlash tili bo'lib, u orqali Android ilovalar, o'yinlar va server dasturlarini yozish mumkin. Termux orqali telefoningizda Java kodlarini yozib, ularni ishga tushirishingiz mumkin.

1. Java (JDK) ni o'rnatish:

pkg install openjdk-17 -y

* O'rnatish tugagach, tekshirib ko'ring. Agar versiya chiqsa, hammasi joyida.

java -version javac -version

2. Java'da kod yozish va ishga tushirish:

Java'da kod yozish uchun avval .java faylini yaratamiz. Fayl nomi albatta katta harf bilan boshlanishi va kod ichidagi class nomi bilan bir xil bo'lishi kerak (masalan: Salom.java).

nano Salom.java

Ichiga quyidagi oddiy kodni yozing:

public class Salom { public static void main(String[] args) { System.out.println("Salom, Termux!"); } }

* Saqlash uchun CTRL + X, keyin Y, keyin Enter bosing.

3. Kodni kompilyatsiya qilish (Tekshirish):

Java kodni to'g'ridan-to'g'ri ishlata olmaydi, avval uni kompilyator orqali .class fayliga aylantirish kerak.

javac Salom.java

* Agar hech qanday xatolik chiqmasa, papkada Salom.class fayli paydo bo'ladi.

4. Kodni ishga tushirish:

Endi kompilyatsiya qilingan faylni ishga tushiramiz.
(Diqqat: ishga tushirishda oxiriga .java yoki .class qo'shilmaydi).

java Salom

Ekranda 'Salom, Termux!' degan yozuv chiqadi. Tabriklaymiz, siz Java'da birinchi dasturingizni yozdingiz!
