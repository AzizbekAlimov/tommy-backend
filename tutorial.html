💻 Termux To'liq Qo'llanma

Ushbu sahifada Termux va dasturlash bo'yicha barcha asosiy ma'lumotlar keltirilgan.

📱 1. Termux Asoslari

Termux - bu Android qurilmalarida Linux muhitini taqdim etuvchi dastur.

  • O'rnatish: F-Droid yoki GitHub orqali yuklab oling.
  • Yangilash: pkg update && pkg upgrade
  • Xotiraga ulanish: termux-setup-storage

🐍 2. Python va Termux

Termuxda Python tilida dastur yozish juda oson.

# Pythonni o'rnatish
pkg install python

# Kod yozish
nano test.py

# Kodni ishga tushirish
python test.py

📂 3. MT Manager Integratsiyasi

MT Manager yordamida Termux fayllarini boshqarish:

  • Termuxda termux-setup-storage buyrug'ini bering.
  • MT Managerda "Add local storage" tugmasini bosing.
  • Termux papkasini topib, ruxsat bering.

☕ 4. Java O'rnatish

Java dasturlash tili uchun muhit:

pkg install openjdk-17
java -version

🌙 5. Lua bilan ishlash

Lua - yengil va tezkor skript tili.

pkg install lua
nano test.lua
lua test.lua

🤖 6. Termuxda Bot Yasash

Python yordamida Telegram bot yaratish:

pkg install python
pip install python-telegram-bot

So'ngra BotFather'dan token olib, kod yozishingiz mumkin.
