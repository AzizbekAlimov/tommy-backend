⚙️ 1. TERMUXNI SOZLASH

Termuxni ochib, dastlabki sozlamalarni bajaramiz va telefon xotirasiga ulanamiz.

pkg update && pkg upgrade -y termux-setup-storage

* termux-setup-storage buyrug'i telefoningiz xotirasiga (rasmlar, yuklamalar) kirishga ruxsat beradi.

📂 2. MT MANAGER BILAN ISHLASH

MT Manager orqali Termux ichidagi fayllarni ko'rish va tahrirlash juda oson. Buning uchun quyidagi qadamlarni bajaring:

  1. Termuxda: termux-setup-storage yozing va ruxsat bering.
  2. MT Manager'ni oching. Chap menyudan Add local storage (Lokal xotira qo'shish) ni bosing.
  3. Ochilgan oynadan Termux papkasini topib, Use this folder (Bu papkadan foydalanish) ni bosing.
  4. Endi MT Manager orqali Termux ichidagi fayllarni bemalol ochib, tahrirlashingiz mumkin.

* Maslahat: Python kodlaringizni MT Managerdagi o'rnatilgan matn muharriri orqali o'zgartirsangiz, xatoliklarni tezroq topasiz.

🐍 3. PYTHON VA PAPKALAR

Python o'rnatib, alohida papkalar yaratamiz va kodlarni ishga tushirishni o'rganamiz (masalan: Tommy/tom.py).

1. Python o'rnatish:

pkg install python -y

2. Papka yaratish va ichiga kirish:

mkdir Tommy cd Tommy

3. Kod yozish uchun fayl ochish:

nano tom.py

* Ichiga print('Salom Tommy') deb yozib, CTRL+X, Y, Enter bilan saqlang.

4. Kodni ishga tushirish (3 xil usul):

# 1. Papka ichida turganda: python tom.py # 2. Papkadan chiqib (cd ..), tashqaridan ishga tushirish: python Tommy/tom.py # 3. Xotiraga ulangan fayllarni ishga tushirish: python /sdcard/Tommy/tom.py
💡 4. Muhim Buyruqlar
  • cd papka_nomi - papkaga kirish
  • cd .. - bir papka orqaga qaytish
  • ls - papkadagi fayllarni ko'rish
  • clear - ekranni tozalash
  • pip install nom - qo'shimcha kutubxona o'rnatish (masalan: pip install requests)
