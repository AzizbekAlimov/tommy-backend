TERMUX TO'LIQ QO'LLANMA
0 dan 100 gacha — Barcha ma'lumotlar
📱 1. TERMUX NIMA VA SOZLASH

Termux — bu Android uchun Linux muhiti. U orqali dasturlash tillarini o'rganish va botlar yasash mumkin.

O'rnatish: F-Droid yoki GitHub orqali yuklab oling.

pkg update && pkg upgrade -y termux-setup-storage
📂 2. MT MANAGER VA FAYLLAR

MT Manager — bu Android uchun kuchli fayl boshqaruvchisi. Termux ichidagi fayllarni ko'rish va tahrirlash uchun uni ulaymiz.

  1. Termuxda: termux-setup-storage yozing va ruxsat bering.
  2. MT Managerda: Add local storage ni bosing.
  3. Termux papkasini tanlab, ruxsat bering.
🐍 3. PYTHON VA TAHRIRLASH

Python o'rnatib, kod yozamiz. Kodni MT Manager orqali ham oson o'zgartirish mumkin.

# Python o'rnatish pkg install python -y # Fayl yaratish nano salom.py

Qanday tahrirlash kerak?

  1. Termuxda kod yozib, saqlang (CTRL+X, Y, Enter).
  2. MT Manager orqali Termux papkasiga kirib, salom.py faylini oching.
  3. Kodni o'zgartirib, saqlang. Termuxda python salom.py deb ishga tushiring.
💡 4. ASOSIY BUYRUQLAR
  • cd papka - papkaga kirish
  • ls - fayllarni ko'rish
  • pkg install nom - dastur o'rnatish
  • clear - ekranni tozalash
