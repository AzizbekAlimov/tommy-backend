⚙️ 1. TERMUXNI SOZLASH

Termuxni ochib, dastlabki sozlamalarni bajaramiz va telefon xotirasiga ulanamiz.

pkg update && pkg upgrade -y termux-setup-storage

* termux-setup-storage telefoningiz xotirasiga kirishga ruxsat beradi.

📂 2. MT MANAGER

MT Manager orqali Termux ichidagi fayllarni ko'rish va tahrirlash juda oson.

  1. MT Manager'ni ochib, Add local storage ni bosing.
  2. Ichki xotiradan Termux papkasini topib, Use this folder ni bosing.
🐍 3. PYTHON VA KUTUBXONALAR

1. Python va Pip o'rnatish:

pkg install python -y

2. Papka va fayl yaratish:

mkdir name cd name nano name.py

3. Kutubxonalar o'rnatish (Pip):

pip install requests pip install beautifulsoup4
💡 4. Muhim Buyruqlar
  • cd papka_nomi - papkaga kirish
  • cd .. - orqaga qaytish
  • ls - fayllarni ko'rish
  • clear - ekranni tozalash
☕ 5. JAVA DASTURLASH

1. Java (JDK) ni o'rnatish:

pkg install openjdk-17 -y

2. Kod yozish:

nano Salom.java // Ichiga yozing: public class Salom { public static void main(String[] args) { System.out.println("Salom, Termux!"); } }

3. Kompilyatsiya qilish va ishga tushirish:

javac Salom.java java Salom
