📱 1. TERMUX NIMA VA O'RNATISH

Termux — bu Android qurilmalarida Linux muhitini taqdim etuvchi dastur. U orqali siz telefoningizda Python, Java, C++ kabi tillarda kod yozishingiz va dasturlar yaratishingiz mumkin.

O'rnatish: Termux'ni F-Droid yoki GitHub orqali yuklab oling. Google Play'dagi eski versiyasidan foydalanmang.

# Birinchi marta ochganda yangilash
pkg update && pkg upgrade -y

# Xotiraga ulanish (ruxsat so'raydi)
termux-setup-storage
☕ 2. JAVA O'RNATISH VA NIMA QILADI

Java nima qiladi? Java — bu dasturlash tili bo'lib, u orqali Android ilovalar, o'yinlar va server dasturlarini yozish mumkin. Termux'da Java o'rnatib, `.java` fayllarini kompilyatsiya qilishingiz va ishga tushirishingiz mumkin.

O'rnatish buyrug'i:

pkg install openjdk-17 -y

# Tekshirish
java -version
Java (OpenJDK) rasmiy sayti
📂 3. MT MANAGER BILAN ULANISH

MT Manager — bu Android uchun kuchli fayl boshqaruvchisi. Termux ichidagi fayllarni ko'rish va tahrirlash uchun uni ulash mumkin.

  1. Termux'da termux-setup-storage buyrug'ini bering va ruxsat bering.
  2. MT Manager'ni oching, chap menyudan "Add local storage" (Lokal xotira qo'shish) ni tanlang.
  3. Ochilgan oynadan Termux papkasini topib, "Use this folder" (Bu papkadan foydalanish) tugmasini bosing.
  4. Endi MT Manager orqali Termux ichidagi barcha fayllarni ko'rishingiz mumkin.
🐍 4. PYTHON O'RNATISH VA ISHLATISH

Python — bu eng oson va ommabop dasturlash tili. Termux'da Python o'rnatib, skriptlar yozishingiz mumkin.

# Python o'rnatish
pkg install python -y

# Kod yozish uchun fayl yaratish
nano ism.py

# Kodni ishga tushirish
python ism.py

Misol: nano salom.py faylini ochib, ichiga print("Salom, Termux!") deb yozing. Saqlash uchun CTRL + X, keyin Y, keyin Enter bosing. So'ngra python salom.py buyrug'i bilan ishga tushiring.

💡 5. TERMUX BO'YICHA QO'SHIMCHA MA'LUMOTLAR
  • Papkalar orasida harakat: cd papka_nomi (kirish), cd .. (orqaga qaytish).
  • Fayllarni ko'rish: ls (joriy papkadagi fayllar).
  • Fayl yaratish: touch fayl.txt.
  • Faylni o'chirish: rm fayl.txt.
  • Paketlarni o'rnatish: pkg install paket_nomi.
  • Paketni o'chirish: pkg uninstall paket_nomi.
  • Yordam: pkg help yoki buyruq --help.
