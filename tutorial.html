⚙️ 1. TERMUXNI SOZLASH

Termuxni ochib, dastlabki sozlamalarni bajaramiz va telefon xotirasiga ulanamiz.

pkg update && pkg upgrade -y termux-setup-storage

* termux-setup-storage telefoningiz xotirasiga kirishga ruxsat beradi.

📂 2. MT MANAGER

MT Manager orqali Termux ichidagi fayllarni ko'rish va tahrirlash juda oson.

  1. MT Manager'ni ochib, Add local storage ni bosing.
  2. Ichki xotiradan Termux papkasini topib, Use this folder ni bosing.
🐍 3. PYTHON VA KUTUBXONALAR

Python — bu eng oson va ommabop dasturlash tili. Termux yordamida telefoningizda to'liq dasturlar va botlar yozishingiz mumkin. Keling, uni 0 dan o'rganamiz.

1. Python va Pip (Kutubxona menejerini) o'rnatish:

pkg install python -y

* -y qismi o'rnatish vaqtida avtomatik "Ha" deb javob berish uchun kerak.

2. Papka yaratish va uning ichiga kirish:

* mkdir (Make Directory) yangi papka ochadi, cd (Change Directory) esa o'sha papkaga kiradi.

mkdir name cd name

3. Kod yozish uchun fayl ochish va kod yozish:

* nano matn muharriri. U orqali .py faylini ochib, ichiga kod yozamiz. Saqlash uchun CTRL+X, keyin Y, keyin Enter ni bosing.

nano name.py # Ichiga shu kodni yozing: print("Salom, Termux!")

4. Kodni ishga tushirish (3 xil usul):

* Qaysi papkada turganingizga qarab, kodni chaqirish usuli o'zgaradi.

# 1-usul: Papka ichida turganda (eng ko'p ishlatiladigani) python name.py # 2-usul: Papkadan chiqib (cd ..), tashqaridan chaqirish python name/name.py # 3-usul: Telefon xotirasidagi faylni chaqirish (masalan, MT Manager orqali) python /sdcard/name/name.py

5. Kutubxonalar o'rnatish (Pip):

Pip — bu tayyor kodlar to'plami. Masalan, internetga ulanish yoki Telegram bot yasash uchun tayyor kodlarni yuklab olish uchun ishlatiladi.

# Internetdan ma'lumot olish uchun: pip install requests # Veb-saytlarni tahlil qilish (parsing) uchun: pip install beautifulsoup4 # Telegram bot yasash uchun: pip install python-telegram-bot
💡 4. Muhim Buyruqlar
  • cd papka_nomi - papkaga kirish
  • cd .. - orqaga qaytish
  • ls - fayllarni ko'rish
  • clear - ekranni tozalash
☕ 5. JAVA DASTURLASH

Java — bu kuchli dasturlash tili bo'lib, u orqali Android ilovalar va o'yinlar yozish mumkin.

1. Java (JDK) ni o'rnatish va tekshirish:

pkg install openjdk-17 -y # Tekshirish: java -version javac -version

2. Kod yozish (Fayl nomi katta harf bilan boshlanadi):

nano Salom.java // Ichiga yozing: public class Salom { public static void main(String[] args) { System.out.println("Salom, Termux!"); } }

3. Kompilyatsiya qilish va ishga tushirish:

* javac - kodni tekshiradi va .class fayl yaratadi. java - kodni ishga tushiradi.

javac Salom.java java Salom
